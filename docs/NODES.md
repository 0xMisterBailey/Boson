# Boson nodes

Generated by `tools/node_docs.py` from the node pack (`boson/`); do not edit by hand. Every node sits
under the `boson` category in ComfyUI's node library. `STUDIO` and `SCENE` are git repos in flight:
a node that changes one commits, and re-queuing a node that already ran commits nothing.

## Studio and loop (15)

### Studio Refs (`BosonStudioRefs`)

The grid's one ref set (02, 08, 01) from the studio itself, for ReferenceMultiLatent. No copy into ComfyUI's input folder: the studio stays the only state.

- In: `studio` STUDIO
- Out: `ref02` IMAGE, `ref08` IMAGE, `ref01` IMAGE

### Grid Row (`BosonGridRow`)

One live row for Grid: a Draft Brief draw at a tag, its pieces rendered at seed a (and b). Wire the same seed primitives into the KSamplers and here, so the readout names the seeds used.

- In: `draft` BOSON_DRAFT, `images_a` IMAGE, `seed_a` INT, `renderer` STRING, `images_b` IMAGE (optional), `seed_b` INT (optional)
- Out: `gridrow` GRIDROW

### Grid (`BosonGrid`)

One row per studio revision, same renderer + ref set in every cell; readout between the rows.

Row at ref X = the round the studio drafted from X (r00 = the forge alone). stored: plates beside the fixture, no key, no LLM call.

- In: `studio` STUDIO, `refs` STRING, `cells` INT, `variant` STRING, `mode` choice, `arm` choice, `row_1` GRIDROW (optional), `row_2` GRIDROW (optional), `row_3` GRIDROW (optional), `row_4` GRIDROW (optional), `row_5` GRIDROW (optional), `row_6` GRIDROW (optional), `row_7` GRIDROW (optional), `row_8` GRIDROW (optional)
- Out: `grid` IMAGE, `readout` STRING

### Load Studio (`BosonLoadStudio`)

A studio is a git repo. ref = a round tag (r00, r01, ...), a branch or a commit; r00 = no history.

- In: `repo` STRING, `ref` STRING
- Out: `studio` STUDIO

### Studio Info (`BosonStudioInfo`)

- In: `studio` STUDIO
- Out: `rules` STRING, `summary` STRING

### Draft Brief (`BosonDraftBrief`)

The writer drafts the next round from the whole studio. Prompts go out as a list, so one stock CLIPTextEncode -> KSampler chain renders every piece.

Writer call (paid, minutes). On a branch the draft is committed as the round; at a tag or commit it is cached by draw. Re-queue reuses it.

- In: `studio` STUDIO, `pieces` INT, `draw` INT, `lead` STRING
- Out: `studio` STUDIO, `prompts` STRING, `brief` STRING, `writer` STRING, `draft` BOSON_DRAFT

### Nano Banana (Boson) (`BosonNanoBanana`)

Renders the studio's drafted round on Nano Banana (Gemini), per the studio's RENDER.json: its refs, then the commission images (the ones wired in, else the studio's own), then lead + each piece's prompt.

live: one Gemini call per piece (needs GEMINI_API_KEY; plates already on disk are reused). stored: the committed plates beside the studio, no key, no call. Not seed-reproducible.

- In: `studio` STUDIO, `mode` choice, `draws` INT, `backend` choice (optional), `image_1` IMAGE (optional), `image_2` IMAGE (optional), `image_3` IMAGE (optional), `image_4` IMAGE (optional), `shot` BOSON_SHOT (optional)
- Out: `images` IMAGE, `studio` STUDIO

### Forge Studio (`BosonForgeStudio`)

Forge a new studio from ~20 references and one sentence: a git repo with STUDIO.md (its practice), JURY.md (its checks) and an empty history, at r00. The writer drafts it (paid, minutes); a re-queue loads it.

refs: a folder of NN.jpg + refs.jsonl with vlm descriptions (tools/fetch_refs.py, describe_refs.py). instrument: a folder with instruments.yaml + render.json (how its rounds are drafted and rendered).

- In: `path` STRING, `owner` STRING, `field` STRING, `sentence` STRING, `refs` STRING, `instrument` STRING, `commission` STRING (optional), `image_1` IMAGE (optional), `image_2` IMAGE (optional), `image_3` IMAGE (optional), `image_4` IMAGE (optional)
- Out: `studio` STUDIO

### Verdict (`BosonVerdict`)

The owner's one-line round verdict. Empty = the graph stops here, quietly, until the owner writes it.

Write one sentence on the round as a whole, then queue again. It is committed to the studio and binds the next round.

- In: `studio` STUDIO, `images` IMAGE, `verdict` STRING
- Out: `studio` STUDIO

### Digest (`BosonDigest`)

The writer turns the verdict into the round's history line, lessons and proposed rules. Nothing it writes binds a round until the owner approves it (Approve Rules).

- In: `studio` STUDIO
- Out: `studio` STUDIO, `proposed` STRING

### Approve Rules (`BosonApproveRules`)

The owner picks which proposed rules bind from now on: "05: 1,3" or "05: none". Wire it from Load Studio; Draft Brief waits until it has run.

- In: `studio` STUDIO, `picks` STRING
- Out: `studio` STUDIO

### Keep Piece (`BosonKeepPiece`)

Puts one of the studio's pieces on the shared shelf (SHELF.jsonl, committed), named studio@sha:path; op unkeep takes it off again (path, or the whole studio@sha:path).

- In: `studio` STUDIO, `path` STRING, `note` STRING, `op` choice (optional)
- Out: `studio` STUDIO, `piece` STRING

### Make (`BosonMake`)

Make n pieces for one frame (a style line or a subject) and the owner's idea: the writer reads the whole studio and writes n render specs (one paid call, minutes), Nano Banana renders them with the studio's refs plus the piece it varies (like), the house pictures, the pins and any wired commission image. Not a round: nothing is committed, no verdict waits. Same inputs again = the same make, no second call.

live: one writer call + one image call per piece (made once, then stored). stored: what this make rendered before, no key, no call. pieces: one studio@sha:path per line, for Keep, Pin, Cast.

- In: `studio` STUDIO, `frame` STRING, `idea` STRING, `n` INT, `mode` choice, `like` STRING (optional), `backend` choice (optional), `image_1` IMAGE (optional), `image_2` IMAGE (optional), `image_3` IMAGE (optional), `image_4` IMAGE (optional)
- Out: `images` IMAGE, `pieces` STRING, `studio` STUDIO

### Edit House (`BosonEditHouse`)

An owner edit of the studio's house, one commit to TASTE.json: the house sentence, descriptor words, style lines, principles, subjects, house pictures and pins (pieces, studio@sha:path). Re-queued, it commits nothing.

- In: `studio` STUDIO, `field` choice, `op` choice, `value` STRING
- Out: `studio` STUDIO, `house` STRING

### Dots (`BosonDots`)

The owner's dots and verdict on a loop round: greens (make more like these, they become the pins), reds (not this) and one sentence on the whole round. Empty verdict: the graph waits here. Re-queued, it commits nothing.

Green = make more like it (pinned), red = not this, then one sentence on the round. Committed to the studio; it binds the next round. brief: the next make's idea (Make it live to spend).

- In: `studio` STUDIO, `round` INT, `greens` STRING, `reds` STRING, `verdict` STRING
- Out: `studio` STUDIO, `brief` STRING

## Scene (13)

### New Scene (`BosonNewScene`)

A new scene repo: from a SCENE.json (spec), or from one piece (from_piece: studio@sha:path) as its base view with no slots yet. Kept in the scene cache as <name>-scene unless path says otherwise. Already on disk: loaded.

- In: `name` STRING, `spec` STRING, `from_piece` STRING, `path` STRING (optional)
- Out: `scene` SCENE

### Load Scene (`BosonLoadScene`)

A scene is its own git repo: SCENE.json (base studio view + slots) and its takes. ref = a branch or a commit.

- In: `repo` STRING, `ref` STRING
- Out: `scene` SCENE

### Load Take (`BosonLoadTake`)

One committed take (empty = the newest) with the boxes Locate found in it.

- In: `scene` SCENE, `take` STRING
- Out: `image` IMAGE, `boxes` BOSON_BOXES, `take` STRING

### Cast (`BosonCast`)

Cast one slot: a swap is this one widget. Nothing is committed; the cast becomes the scene with the next take, so swaps stay pending until a re-shoot (or one Swap edit).

- In: `scene` SCENE, `slot` STRING, `piece` STRING, `desc` STRING (optional), `short` STRING (optional)
- Out: `scene` SCENE

### Add Slot (`BosonAddSlot`)

Make a slot from the frame: something the base shows and no slot holds yet (an anchor Locate already boxes, e.g. the taqueria) becomes a slot a studio can fill. Commits SCENE.json; the slot holds the base's own pixels until a piece is cast, so nothing re-renders until a Swap. The same slot again commits nothing.

- In: `scene` SCENE, `anchor` STRING, `slot` STRING, `noun` STRING, `studio` STRING, `where` STRING (optional), `box` STRING (optional)
- Out: `scene` SCENE

### Compile Scene (`BosonCompileScene`)

SCENE -> the ordered images and the prompt for Nano Banana's `shot` input. Deterministic, no model call: a close-crop worn swap's clothes-only card is made by Nano Banana when it renders live (once, cached). shoot: image 1 = the blocking plate (stand-ins drawn on the base view). swap: image 1 = the last shoot take, edited so only the swapped slots change. take: the TAKE block (hour, weather, street life); empty leaves <<TAKE>> for the base studio's writer (Draft Brief) to fill per piece.

- In: `scene` SCENE, `mode` choice, `take` STRING, `worn` choice (optional)
- Out: `shot` BOSON_SHOT, `images` IMAGE, `prompt` STRING

### Uncrop (`BosonUncrop`)

Puts a close-crop edit back into its take: only the person (the mask, from core's Remove Background on the edit), so the crop's own background never shows; where the old wearer was wider, the take's background is filled in from around them. No mask wired: BiRefNet runs here (boson/segment.py), as it always does for the old wearer. A shot without a crop passes the image through.

- In: `image` IMAGE, `shot` BOSON_SHOT, `mask` MASK (optional)
- Out: `image` IMAGE

### Locate (`BosonLocate`)

Finds every slot in a take: one Gemini vision call per take (a few cents), cached by pixels. stored: never calls (a committed take's boxes, or the cache).

- In: `image` IMAGE, `scene` SCENE, `mode` choice, `model` STRING
- Out: `boxes` BOSON_BOXES, `readout` STRING

### Slot Crop (`BosonSlotCrop`)

The slot's located box in a take (padded), as that slot studio's commission image ("ask for new").

- In: `image` IMAGE, `boxes` BOSON_BOXES, `slot` STRING, `item` INT, `pad` FLOAT, `scene` SCENE (optional)
- Out: `image` IMAGE

### Paste Flat (`BosonPasteFlat`)

Perspective-warps a flat piece (a poster, a sign) onto each quad Locate found for the slot. The piece is the slot's cast piece unless one is wired in. glass: how much of the take shows through (reflection, tint).

- In: `image` IMAGE, `boxes` BOSON_BOXES, `scene` SCENE, `slot` STRING, `glass` FLOAT, `flat` IMAGE (optional)
- Out: `image` IMAGE

### Commit Take (`BosonCommitTake`)

Commits the take: its image, the cast it was shot with, Locate's boxes. A take is a commit, never rewritten; the same pixels again commit nothing.

- In: `scene` SCENE, `image` IMAGE, `boxes` BOSON_BOXES, `shot` BOSON_SHOT (optional)
- Out: `scene` SCENE

### Commit Clip (`BosonCommitClip`)

Commits a clip made from one take: the video from any video node (Comfy's partner Gemini Omni, LTX, a local model) and the words it was moved by. The clip lives in the scene repo beside its take; the same bytes again commit nothing. Stored mode replays it with Load Clip, no key.

- In: `scene` SCENE, `video` VIDEO, `take` STRING, `prompt` STRING, `renderer` STRING
- Out: `scene` SCENE, `clip` STRING

### Load Clip (`BosonLoadClip`)

One committed clip (empty = the newest), straight from the scene repo: no key, no call.

- In: `scene` SCENE, `clip` STRING
- Out: `video` VIDEO, `prompt` STRING
