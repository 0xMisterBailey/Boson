The instrument this round (it replaces the renderer in `instruments.yaml`; keep that file's other
settings where they do not conflict): FLUX 3 Klein, image editing from three of the studio's own
reference prints, refs/{REFS}. Every prompt is placed after the line "In the engraving style and
composition of the reference prints:", so write the plate, not the style instruction. It renders what the
prompt names and borrows layout, density and surface from the reference prints.

Anti-template rule (binding for this round, from the studio's render test): do not dictate a layout no
reference print uses. No "EX LIBRIS" band across the top, no rectangular name tablet, no ruled border,
no "filling the frame with a margin of clean paper", unless you name the reference print (by number)
that uses it. The words "EX LIBRIS" and the owner's name must still appear; say what carries them in
terms a reference print uses (a ribbon, a scroll, a cartouche, lettering in the field), or let the
composition place them.
